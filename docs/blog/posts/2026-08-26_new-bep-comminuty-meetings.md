# 📣 NEW: BEP Community Meetings

We're starting a quarterly BEP Community Meeting to help extension proposals move faster, stay coordinated with each other, and get consistent support from the maintainers. Everyone is welcome and we especially encourage BEP leads and anyone with a major change request for an ongoing BEP to join.

**What it is**: a 90-minute online meeting, split two ways:

- short (each ≤5 min) updates from active BEPs.
- discussion and resolution of a few cross-cutting issues.

**First meeting: October 1st 2026 3pm UTC · [Zoom link](https://mcgill.zoom.us/j/88998133033?pwd=qfguDJDzpDFQsn1jG1MvqSQZehNglA.1)**

**If you lead a BEP**: please add your update to the shared template before the call ([Slide template](https://docs.google.com/presentation/d/1aD-VW7ZRzA9dJCJYvi20ipqItxWwOi8Zv1oPn5p4pog/edit?usp=drive_link)). Only BEPs with changes or an ask will present live but every BEP should fill in the one-slide status so the community has the full picture.

**Want an issue discussed?** Nominate it using the label community-meeting on the respective BIDS repository on GitHub. The repo carrying the issue/ PR must be under the bids-standard GitHub organization, otherwise it won’t be added to the BIDS GitHub project from which maintainers will choose the issues to be discussed. Labels exist in all BIDS GitHub repos already.
